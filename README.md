# Браузерная валентинка ❤️

Откройте `index.html` в браузере.

Что внутри:
- розовый анимированный фон;
- жёлтый подарок с красным бантиком;
- лёгкое «дыхание» подарка;
- раскрытие подарка по клику;
- появление пульсирующего сердца;
- надпись «Я тебя люблю»;
- адаптация под мобильные экраны.

Никаких библиотек и сервера — только HTML, CSS и JavaScript.
